# MaxOff v2.0: the Owner's phone walk (about 15 minutes)

Use the **installed app on your phone**, on the **preview** of this release (`https://phase-v2-maxoff-staging.pixoraclips.workers.dev`, release candidate 566bb2d7), never on the live app.
You need three sign-ins: you (Owner), the test Admin, the test Crew member.
Before you start, have ready: one client run by the test Admin with a working project, and one task given to the test Crew member.

Each step: **do this → you should see this.**

## As Owner (about 7 minutes)

1. **Open the app on Today** → Today appears with its content. The "Needs you" list does not show an empty box first, and the card under it does not jump down.
2. **Tap Tasks. Then tap exactly on a chip in a task row** (for example "2 days late" or "To do"), not on the title → the task opens.
3. **In that task, tap ⋯** → every item in the menu is the same size and lines up. "Put on hold…" is no smaller than "Edit task".
4. **Tap "Put on hold…", give a reason, confirm** (use the test Crew member's task) → the amber "On hold" chip, the reason, and under it: "Start, Done and the stage ticks wait until the task is resumed."
5. **Tap ⋯ again** → "Resume" is the same size as the other items. Close the menu. Leave the task on hold.
6. **Tap More → Clients → the test Admin's client** → the page loads without jumping. Key people stays where it first appeared.
7. **Open the working project. Tap ⋯ → "Put on hold…", give a reason, confirm** → the amber banner. While here, tap ⋯ again: "Copy schedule as text" is the same size as the rest.
8. **Tap one deliverable in that project** → the sheet's header reads "On hold". At the top: "The project is on hold: ticks and Mark done wait until it is resumed." The stages are greyed out, **but their names are easy to read** (check in Dark too after step 11). Tapping a stage does nothing. Tap the sheet's ⋯: all items the same size.
9. **Go back to the client. Look at Overview, then the Projects tab** → the project's row shows an amber "On hold", not "Open".
10. **Tap More → Appearance** → a small sheet "Appearance" slides up with Light, Dark and System. Your current one is ticked. It does not flash and close.
11. **Tap Dark** → the sheet closes by itself. The app is dark. The More row reads "Appearance · Dark".
12. **Press back once** → More closes. **Press back again** → you leave the screen you were on. No back press does nothing.
13. **Tap Calendar, and at once tap a day** (do not wait for it to settle) → the day opens as soon as the calendar is ready. Your tap is not lost. Try the same with the handle that changes the calendar's size.
14. **Open Approvals, then a task, then More → Settings → Templates** → each opens quickly, with no grey outline that jumps.

## As the test Admin (about 3 minutes)

15. **Sign in as the Admin. Open Today** → "Client work" rows keep their place while loading. Nothing jumps.
16. **Tap More → Clients → the same client** → the project you held as Owner reads "On hold" on Overview and on the Projects tab.
17. **Open that project, then a deliverable** → "On hold" in the header, the amber line saying why ticks and Mark done wait, greyed stages whose names are easy to read. The Admin did not have to try a tick to find out.
18. **Tap More → Appearance → Light, then back twice** → same as steps 10 to 12.
19. **On Tasks, tap a chip on a row** → the task opens.

## As the test Crew member (about 3 minutes)

20. **Sign in as Crew. Open My Day** → it opens quickly. Under the lists there is a line "On hold · 1".
21. **Tap "On hold · 1"** → the held task is listed. Open it: the amber line with your reason. No Start or Done.
22. **Go to Tasks and tap a chip on a task row** → the task opens.
23. **Tap Calendar and at once tap a day** → it opens as soon as the calendar is ready.
24. **On My Day, tap End day** (only if the test person has started their day) → the question about expenses appears without a wait.

Open **Me → How MaxOff works** as each role and read these topics. Each should say what you just saw.

26. **Admin:** "The bell and Me" (More → Appearance), "The Tasks screen", "Put a task on hold, and resume it", "Put a project on hold, and resume it", "Use the calendar".
