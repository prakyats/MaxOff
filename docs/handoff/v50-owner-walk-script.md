# MaxOff v5.0 "Hand in work": the Owner's phone walk (about 20 minutes)

Use the **installed app on your phone**, on the **preview** of this release (`https://phase-v50-maxoff-staging.pixoraclips.workers.dev`, release candidate ‹sha at READY›), never on the live app. Part of it is on a laptop (adding a folder), and part needs the **studio's Google account** in your browser (opening files in Drive).
You need three sign-ins: you (Owner), the test Admin, the test Crew member.
Before you start, have ready:
- the studio Drive connected on the preview (Settings → Google Drive says "Connected");
- one **normal task** given to the test Crew member with the test Admin approving, noted and started;
- one **Meeting task** given to the test Crew member;
- on the Crew member's phone, two photos and one short video.

Each step: **do this → you should see this.**

## As Owner: the setting (about 3 minutes)

1. **More → Settings → Task types** → every type's row reads as before; none says "no hand-in" (every type starts with "Has hand-in" on).
2. **Open Meeting (Edit), untick "Has hand-in", Save** → "Task type saved"; Meeting's row now ends "· no hand-in". The line under the box says files are never required to mark a task done.

## As the test Crew member: handing in (about 7 minutes)

3. **Open the normal task** → under the stages, a **Files** section: "v1 · not handed in yet" and **Add photos and videos**.
4. **Tap Add photos and videos, pick the two photos and the video** → each file shows its progress, then **In Drive** (green). The line on top counts them ("2 of 3 · …"). While they upload there is a note to keep MaxOff open.
5. **While one is still uploading, go to My Day and come back** → the upload kept going; the card shows where it is.
6. **On one photo, tap Leave out, then press back** → the question closes and the task stays. **Tap Leave out again and confirm** → the photo moves to "1 left out"; it says MaxOff never deletes files.
7. **Tap Mark done** → the sheet says **"Hand-in v1 · 2 files"**. Confirm → the task goes to the Admin.
8. **Open the Meeting task** → **no Files section at all**. Mark done works as before (don't finish it).
9. *(Laptop, optional)* **Open a third task in a browser, Choose a folder** → the files keep their folders; a folder that is too deep is refused with a clear message.

## As the test Admin: reviewing (about 5 minutes)

10. **Open Approvals** → the task's row says **"v1 · 2 files"**.
11. **Open the task** → Files shows **v1 handed in**, who and when, and each file's name and size. **Open in Drive** on a file opens it in Google Drive (the studio account); **Open the v1 folder in Drive** opens the folder. A risky type (if you added one) shows "Check before opening".
12. **Tap Request changes** → the box asks to **"Name the files that need changes, and say what to fix."**, and says new files go into the next version. Write "Re-export the video" and send.
13. **As Crew, open the task again** → the reason sits above **"v2 · not handed in yet"**; v1 is collapsed and unchanged. Add one file → it goes into v2. Mark done says "Hand-in v2 · 1 file".

## As Owner: the result (about 3 minutes)

14. **Open the task (Approvals or Tasks)** → v2 handed in with its file; v1 below with its send-back reason. Both Drive links work for you.
15. **In the studio Drive** (a browser on the studio account) → the task's folder has **v1** and **v2**; the left-out photo is still in v1 (MaxOff never deletes). The files are full quality, with the Crew member's own names.
16. **Approve** → the task completes. The notification and history say "v2 · 1 file".

## The guide (about 2 minutes)

Open **Me → How MaxOff works** as each role and read these topics:
17. **Owner:** "Edit task types" (Has hand-in), "Open the files handed in".
18. **Admin:** "Open the files handed in".
19. **Crew:** "Add your photos and videos" (and that a meeting or call has no Files section).

## Tidy up

20. **As Owner:** tick "Has hand-in" back on Meeting if you want meetings to take files; otherwise leave it off. The test files stay in the studio Drive's test task folder: delete them there if you like (MaxOff never does).

## Last check

21. **Anything that looks different from today's app and is not on this list is a bug. Tell me.**
