On 2026-10-16 the owner said: "All UI changes shall be released at once, so that it doesn't get confused for the team" (when adding the one-page Templates restructure to v1.7.1 instead of a later release).

**Why:** the team uses MaxOff daily; screens that shift every few days confuse them. One release, one team message, one guide update.
**How to apply:** when a UI change comes up near a release, prefer folding it into that release rather than spreading UI changes over several releases. If it would endanger the release, say so and ask; don't silently defer. Pairs with [[app-guide-single-source]] (the guide must match each release).
