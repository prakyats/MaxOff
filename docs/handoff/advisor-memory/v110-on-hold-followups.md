Owner approved v1.9 after the phone walk on 4 Nov 2026 and asked for these changes in the **next** release, not v1.9:
1. **Everyone linked to a held task sees it as held.** The Crew assignees must be told that the task is on hold.
2. **A project the Owner holds must show as on hold to the Admin** who opens it. In v1.9 the Admin sees nothing.
3. **Say it up front, not on a tap.** On a held task, the "you can't tick a stage, the task is on hold" message appears only when someone taps a stage. Instead, show the on-hold message as soon as the task or project opens, to the Admin and to everyone linked to it, not only the Owner.
4. **Phone:** the "Put on hold" wording shrinks on mobile. Make it display at its proper size.

Also for the next release: the start-order race fix (`v19-first-reads`) and any Crew speed routes still failing.

**How to apply:** add all of this to ROADMAP after the v1.9 merge. It ships as the next version's first UI unit. Check it on the phone at 375/430 ([[phone-layouts-stay-live]]).
