Never hard-code Pixora's business process (the six-step Understand→Optimize framework, the services, the Business Audit) as rules the software enforces. The user said each client's requirements are different. What stays the same is the kind of information kept (brand guidelines, identity, requirements, monthly workflow, monthly deliverables), and the content is specific to each client.

**Why:** the user shared Pixora's business details only to explain the business, and wants maximum customization per client and room to expand at any time.

**How to apply:** model business vocabulary as editable data (lists, custom fields, per-project statuses and phases, global or client-specific templates). Code may depend only on fixed categories. Framework gates are optional, turned on per template. Related: [[maxoff-project]].
