# MaxOff v2.1 "Money in": the Owner's phone walk (about 15 minutes)

Use the **installed app on your phone**, on the **preview** of this release (`https://phase-v21-money-maxoff-staging.pixoraclips.workers.dev`), never on the live app.
You need two sign-ins: you (Owner) and the test Admin.
Before you start, have ready on the preview: one client run by the test Admin with **a monthly project** (a few deliverables this month) and **a one-time project** with two deliverables, both still open.

Amounts you type here are test amounts on staging. Nobody but you can see them.

Each step: **do this → you should see this.**

## As Owner: a monthly project (about 5 minutes)

1. **More → Clients → the client → the monthly project. Scroll to the end** → a new section, **Billing**: Category "Retainer", "Amount per month · No amount set", and this month's Potential / Achieved / Remaining at ₹0. The section appears a moment after the page, and nothing above it moves.
2. **Tap "Set amount". Type 10000.50** → it refuses: whole rupees only. **Type 10000 and save** → "₹10,000". The sheet says the amount applies from this month on. Potential is ₹10,000.
3. **Press back while a Billing sheet is open** → only the sheet closes.
4. **Tap "Change" beside Category, pick "Additional Work", save** → the category changes. The amount stays.
5. **Add a deliverable to this month** (the Deliverables list's "Add") **and scroll back to Billing** → "Added this month" lists it as **Not priced**. Potential is still ₹10,000.
6. **Tap "Set price", type 2000, save** → it shows ₹2,000 and Potential becomes **₹12,000** (the extra is on top).
7. **Mark one planned deliverable done** → Achieved rises by that deliverable's share. Remaining falls by the same.
8. **Switch to last month with the month switcher (if the project has one)** → it reads "No amount set", and a row **"Set this month's amount"**. Set one → only that month changes.

## As Owner: a one-time project (about 4 minutes)

9. **Open the one-time project. Scroll to Billing** → Category "Project", "Amount · No amount set". No "Record advance" yet.
10. **Set the amount to 60000** → "₹60,000". Now **"Record advance"** appears.
11. **Record an advance of 30000, today, note "On signing"** → "Advance received ₹30,000 · Balance on delivery ₹30,000" and the advance's row.
12. **Try a second advance of 40000** → refused: advances can't add up to more than the amount.
13. **Mark the first deliverable done** → it is simply marked done, as before.
14. **Mark the second (last) deliverable done** → a sheet: **"Complete the project too?"** with **"Mark done and complete project"** and "Mark done only". Press back → the sheet closes and nothing is marked.
15. **Tap Mark done again → "Mark done only"** → the deliverable is done, the project reads **"Ready to complete"**, and a message offers **"Complete project"**. Leave it.

## As Owner: the Revenue page (about 3 minutes)

16. **More → Reports** → a new row, **Revenue**. Tap it.
17. **Look at the top** → this month's Potential / Achieved / Remaining, and "Advances received ₹30,000" on its own line (not inside Achieved).
18. **Look at "Needs a look"** → the one-time project as **"Ready to complete"**, and any project with "No amount set" or deliverables "not priced". Tap a row → it opens that project.
19. **Press back** → you are on Revenue again. **Tap the month arrows and the category filter a few times, then press back once** → you leave Revenue in one step (the arrows and filter are not steps to go back through).
20. **Open the one-time project from "Ready to complete" → ⋯ → Complete project** → completed. **Back to Revenue** → its ₹60,000 is now in Achieved.

## As the test Admin (about 3 minutes)

21. **Sign in as the Admin. Open the same monthly project and scroll to the end** → **no Billing section**, and no rupee amount anywhere on the page.
22. **More → Reports** → the Admin's work report, with **no Revenue row**.
23. **Open a one-time project of this client with one deliverable left. Mark it done** → the same sheet, "Complete the project too?", with **no amount in it**. Choose **"Mark done and complete project"** → the project is completed.
24. **Open Today (as the Admin), and mark the last deliverable of another one-time project done there** (if you have one) → it is marked done, and after the Undo a message says the project is ready to complete, with "Complete project".

## Last, as Owner

25. **More → Help → "How MaxOff works" → Billing** → "Set a project's billing", "Price added deliverables", "Record an advance", "Read the Revenue page", each with its picture.

**Tell the advisor anything that looked wrong, with the step number.**
