# MaxOff v2.0 "Fast and settled": what changed since v1.9

v2.0 adds no new feature. It makes the app faster and steadier, and fixes rough edges the team reported.

- **The speed gate passed for every role**, under the rule you set in CLAUDE.md. A one-off slow reading was always measured again; a screen only counts as slower if it's slower twice in a row.

## 2. How it got faster (in plain words)

1. **Fewer trips to the database.** Each screen now fetches everything in one or two requests instead of many small ones.
2. **The first response already contains the page.** Likely next screens are loaded ahead of time for every role.
3. **Faster permission checks.** The database's "who can see what" checks were rewritten to run faster. Tests prove they give exactly the same answers as before.
4. **A tapped task always shows its outline at once.** Before, right after the app reopened or a live update arrived, the old screen sometimes stayed up for 0.4–3 seconds; v1.9 did this too. This was the last fix, made this week.

## 3. What people will see change

**Everyone**
- Screens open faster, especially a task, Tasks, a client, a project, Templates and My Day.
- Tapping anywhere on a task row now opens the task, including the chips ("2 days late", "Note it").
- Tapping a day on the Calendar while it's still loading opens that day as soon as it's ready.
- Phone menus are all the same size. "Put on hold…" and "Resume" used to be smaller.

**Owner and Admins**
- Today's "Needs you" and "Client work" no longer jump while loading.
- Client and project pages load without a jump.
- **On hold is clear everywhere.** A held project shows an amber "On hold" on the client's page. Its deliverables say why ticks wait, and its stages are greyed once, so they're still readable. Admins can now see when you've put their project on hold.
- On the phone, More → Appearance opens a small Light / Dark / System sheet.

**Crew**
- My Day shows "On hold · 1" instead of the held task disappearing.
- End day is ready sooner.

## 4. Safety

- **14 database changes, all additions.** Nothing is removed or rewritten, so going back to v1.9 means switching only the app back, with no database step.
- **No new passwords, settings or scheduled jobs.** It's safe to deploy at any time of day.
- **Checked before release:** both full GitHub test runs passed on the first try, a code review (with must-fix items fixed), your phone walk, the guide check, and the India speed check for all three roles.

## 5. Known issues (planned for v2.1)

- **Settings → Thresholds:** typing straight after pressing Save can lose that edit. Wait a moment after Save.
- **Some taps can still be slow right after the app reopens.** A tap on a bottom tab, or on a client, project or person, can wait for the server; v1.9 does the same. The new instant outline covers task taps only for now.
